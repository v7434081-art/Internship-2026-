# ⚙️ How to Run Locally

Follow these steps to run the projects on your computer.

## 1. Clone the Repository

```bash
git clone https://github.com/v7434081-art/Internship-2026.git
```

## 2. Navigate to the Project

```bash
cd Internship-2026
```

## 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

## 4. Run the Student Dashboard

```bash
streamlit run dashboard.py
```

## 5. Run the Feedback Form

```bash
streamlit run form.py
```

## 6. Run the Unit Converter

```bash
streamlit run unit-converter.py
```

The selected Streamlit application will open in your browser.
