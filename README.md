# Internship-2026

A collection of Python and Streamlit projects developed during my **Internship 2026**. This repository contains beginner-friendly applications focused on data handling, user interaction, and web application development using Python.

## 📁 Projects

### 1. Student Dashboard

A Streamlit-based dashboard that displays and analyzes student data from a CSV file.

**Features:**

* View student records
* Filter students by different criteria
* Analyze student marks
* Interactive dashboard interface
* Uses `students.csv` as the data source

**File:** `dashboard.py`

---

### 2. Feedback Form

An interactive feedback form developed using Streamlit.

**Features:**

* User-friendly input form
* Collects feedback from users
* Multiple input fields
* Interactive Streamlit components

**File:** `form.py`

---

### 3. Unit Converter

A simple unit conversion application built with Python and Streamlit.

**Features:**

* Easy-to-use interface
* Converts values between different units
* Interactive input and output
* Simple and beginner-friendly design

**File:** `unit-converter.py`

---

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/v7434081-art/Internship-2026.git
```

### 2. Open the project folder

```bash
cd Internship-2026
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

## ▶️ Run the Applications

### Student Dashboard

```bash
streamlit run dashboard.py
```

### Feedback Form

```bash
streamlit run form.py
```

### Unit Converter

```bash
streamlit run unit-converter.py
```
